# 设计令牌映射表(统一设计语言·第 1 步)

目标:颜色只在一个地方定义,其余体系只做别名,改一处全站生效。

## 三层结构(都在 `app/tokens.css`)
1. **调色板常量 `--pal-light-*` / `--pal-dark-*`**:唯一允许写原始色值的地方。浅色是象牙纸张色,深色是海军蓝。
2. **语义令牌 `--ds-*`**:随全局主题(`html[data-theme]`,以及 `.rwa-mobile[data-theme]`)在浅/深两组调色板之间切换。
3. **各体系的变量**:全部指向第 2 层(或登录页直接指向第 1 层)。

## 各体系如何映射
| 体系 | 变量 | 处理 | 外观变化 |
|---|---|---|---|
| Maison | `--m-bg/ink/muted/faint/line/line-soft/accent/on-accent/up/down/warn/sea` | 改为 `var(--ds-*)`;深色块里删除重复定义 | **无**(浅/深色值与之前逐项一致,已在浏览器里核对) |
| Maison | `--m-lacquer-*`、`--m-cta-*`、阴影、`--m-glass*`、圆角、字体、缓动 | **保留**,是 Maison 专属组件令牌 | 无 |
| 登录/注册 | `--ink`、`--auth-muted/faint/accent`(暖/冷) | 暖→`--pal-light-*`,冷→`--pal-dark-*`(登录页的冷暖主题独立于全局主题,所以直接引用调色板) | 冷色 muted `#9aa6b8→#97a3b6`、faint `#68758c→#647088`,差异极小 |
| 登录/注册 | `--auth-bg`、`--card*`、`--field*`、`--shadow` 等 | **保留**(海报背景专属) | 无 |
| 旧外壳 | `--bg/--surface/--surface-2/--ink/--ink-2/--ink-3/--accent/--up/--down/--warn/--info` | 改为 `--ds-*` 别名 | **有,见下** |
| 首页 | `--home-*`(50 个) | **本步保留不动**:首页是照片加玻璃质感,暖/冷主题色板是它自己的,留到第 3 步处理 | 无 |

## 旧外壳的可见变化(第 1 步唯一的外观改动)
- 强调色:青绿 `#0F5C5A`(深色 `#7FE0C8`)→ 金铜 `#8a6a3b`(深色 `#e3bb7a`)。
- 底色/文字:`#F4F1EA→#f4efe6`、`#FFFFFF→#fffdf8`、`#0E1116→#1b1813`(偏暖)。
- 次要文字:`--ink-2 #4A5058→#4a433a`;`--ink-3 #6E747D→#6b6257`(**没有**用 Maison 的 faint `#9a8f82`,避免旧页面小字对比度变差)。
- 深色:中性黑 `#0A0B0D` → 海军蓝 `#070c16`;`--surface #13151A→#0e1626`、`--surface-2 #1B1E25→#16213a`。
- 状态色:`--up #1F7A4D→#3f7a57`、`--down #B4322F→#b0533f`、`--warn #B8860B→#a4701f`。
- 受影响范围:仍使用旧变量的页面和全局元素(全局提示条、旧订单状态/篮子/披露页、图表颜色等)。

## 之后的规则
- 新代码**不得**写原始色值,只能用 `--ds-*`(或 Maison 内的 `--m-*`)。
- 想改品牌色,只改 `--pal-*`。
