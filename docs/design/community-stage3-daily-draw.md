# 社区第三期：每日抽奖 + 积分 / 减免券（设计稿，等你批准）

2026-11-01。这一期会改到收手续费的地方，所以先给你看设计，你同意后再写代码。

## 一句话
每天第一次发晒单卡片，可以翻一张奖励卡。奖品是**积分**或**手续费减免券**。不发现金，不能提现，不能转给别人。

## 我的建议（设计判断）
1. **每次都有奖，没有「谢谢参与」**。最少也有积分。空奖会让人觉得被骗，也更像赌博。
2. **第一版只做两种券**，因为它们的费用最简单、最好核对：
   - **预测下注费减免券**：下注时少收下注费，最多减 X USDT。
   - **提现手续费券**：免一次提现手续费。
   - 量化赎回费（分档、按批次算）和管理费、业绩费，**第一版不做**。以后再加。
3. **积分要有用处**，不然没人在乎。第一版：积分可以换减免券（例如 100 积分换一张下注费券）。以后再做积分商城。
4. **奖品和发帖赚多少钱没有关系**。亏损的卡片也一样能抽，奖品概率完全一样。这样不会鼓励大家只晒盈利、或者为了晒单去冒险。

## 谁能抽
- 每个账号，按新加坡时间，每天一次。数据库用唯一约束（活动、账号、日期）保证。
- 必须是这一天**第一次发出的晒单卡片**。量化、预测、资金记录卡都算。
- 注册不满 24 小时的账号不能抽。
- 发卡片后删帖，当天也不能再抽；已经抽到的奖品照样保留，抽奖记录也保留。
- 同一台设备或同一个网络，一天里有多个账号来抽，会被标记，奖品先冻结，后台审核。

## 抽奖界面（前端，我来写）
1. 发出卡片后，帖子出现在列表里，底部弹出一张小卡：「今天的奖励 · 点一下翻开」。
2. 点一下，卡片翻过来，显示奖品，例如「下注费减免券 · 最多减 0.50 USDT · 14 天内有效」。
3. 两个按钮：「去券包」和「好的」。
4. 关掉也没关系：今天的抽奖会留在「我 → 券包」最上面，还能再翻。
5. 样式：沿用晒单卡的票据外形（顶部色带 + 齿孔线），翻转动画 0.5 秒，不用彩带、星星这类装饰。
6. 「我」页面加一行「券包 · 积分」，显示积分余额和可用的券。

## 用券（会碰钱，最要小心）
- 下注确认页、提现确认页里，如果有能用的券，会多一行：「使用减免券 −0.30 USDT」，默认选上，可以关掉。
- 一笔订单只能用一张券。
- 服务器在**同一个事务**里完成：检查券 → 锁住券 → 算费用 → 扣款 → 把券标成已用。订单失败，券自动退回。
- 前端传来的减免金额一律不用，服务器自己算。
- 减免金额不能超过这笔订单本来要收的手续费，手续费不会变成负数。
- 记账：订单上记下「原手续费、减免金额、实收手续费、用的哪张券」。平台收入报表里分开显示「手续费总额」和「促销减免」，方便对账。

## 奖品怎么定（后台配置）
- 后台有一张奖品表：奖品种类、面值、权重（概率）、每天最多发多少张、开关。
- 每天有一个**总预算**（例如每天最多发出 50 USDT 面值的券）。预算用完后，当天只发积分。
- 抽奖结果由服务器用安全随机数决定，每次抽奖都记录下来：谁、什么时候、抽到什么、当时的概率表版本。
- 建议的第一版奖品表（你可以改）：

| 奖品 | 面值 | 概率 |
|---|---|---|
| 积分 | 10 | 60% |
| 积分 | 30 | 25% |
| 下注费减免券 | 最多减 0.50 USDT | 10% |
| 提现手续费券 | 免一次 | 5% |

## 数据表（后端，交给 Codex）
只加表，不改旧表的意思：
- `reward_campaigns`：活动（每日晒单抽奖），开始和结束时间、开关、每日预算。
- `reward_prizes`：奖品表，带版本号。
- `reward_draws`：抽奖记录，唯一约束（campaign_id, user_id, sg_date），关联那条卡片帖。
- `user_points_ledger`：积分流水，只追加，不修改。余额 = 流水合计。
- `user_coupons`：券（种类、最多减多少、过期时间、状态：可用 / 锁定 / 已用 / 过期 / 冻结）。
- `coupon_redemptions`：用券记录，关联订单，记下减免金额。
- 预测下注表和提现表各加两列：`fee_discount_atomic`、`coupon_id`。

## 接口
- `GET /v1/rewards/today`：今天能不能抽、抽过没有、抽到什么。
- `POST /v1/rewards/draw`：翻卡（防重复提交）。
- `GET /v1/rewards/wallet`：积分余额、券列表。
- `POST /v1/rewards/points/exchange`：积分换券。
- 下注和提现的报价接口返回可用的券和减免后的费用；下单接口加 `couponId`。

## 测试（后端必须写）
- 同一天抽两次，第二次被拒绝；并发抽两次，只成功一次。
- 删帖后不能再抽。
- 用券后实收手续费正确，不会是负数；订单失败券会退回。
- 同一张券并发用两次，只成功一次。
- 预算用完后只发积分。

## 上线顺序
1. 后端（Codex）+ 前端（我）都放在开关后面，默认关。
2. 备份 → 迁移 → 切换后端 → 部署前端（命令我自己执行）。
3. 你在手机上用自己的账号试：发卡 → 翻卡 → 用券下注一笔小额。
4. 没问题再打开开关给所有人。

## 合规（请你确认）
新加坡对「促销抽奖」有专门规定（赌博管理局 GRA 的 trade promotion 类别）。每次都有奖、不花钱就能参加，风险会小一些，但我不是律师，请你在打开开关前确认：
https://www.gra.gov.sg/licenses-approvals/class-licences/faq-for-trade-promotion-games-of-chance-and-lotteries
