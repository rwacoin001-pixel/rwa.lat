# A-REIT 设计语言 · Paper & Glass（唯一现行规范）

更新：2026-10-26。旧的设计规则、设计合同、令牌映射表、HIG 复核和 QA 记录已于同日删除（git 历史可查），以本文为准。
2026-10-26 起是唯一的设计；旧配色、旧页面代码和 `?palette=classic` 开关已删除。

## 1. 气质
冷白纸面 + 一点玻璃。安静、精致、有质感，不靠花哨颜色。参考 Apple 与 Radium 的克制，但不照搬。

## 2. 颜色（`styles/palette-a.css`）
- 浅色：底 `#f5f6f8`，面 `#ffffff`，字 `#0b1220`，次要字 `#5b6472`。
- 深色：底 `#0a0c10`，面 `#14171d`，字 `#f2f4f7`。
- 品牌青：浅色文字用 `#087a67`/`#0a8a73`，深色与标记用 `#19c7aa`。
- 涨跌：浅 `#067a5e` / `#c23b33`（小字也够 4.5:1 对比度），深 `#2fd4a3` / `#ff6b5e`。
- 青色只用在少数地方：选中、主数据、品牌标记。不做大面积底色。

## 3. 字体
- 拉丁字母和数字：**Satoshi**（自托管 `public/fonts/satoshi`，400/500/700/900）。
- 中文：苹果设备用**苹方**；华为、荣耀用本机的**鸿蒙黑体**；其他设备用**思源黑体**（Noto Sans SC，OFL 授权，自托管切片 `public/fonts/noto-sans-sc`，`styles/noto-sans-sc.css`，页面用到哪块才下载）。
  App 自己文案里的字（约 1,200 个）用精简文件 `public/fonts/noto-sans-sc-app`（共约 400 KB）；其他字（名字、新闻、服务器消息）用完整切片。两种文件在同一个字体名下，字符不重叠，所以每个字只下载一个文件。`styles/noto-sans-sc.css` 由 `scripts/fonts/subset_noto_app.py` 生成，**加了新的中文文案后重新跑一次**（不跑也不会缺字，只是新字走完整切片）。
  鸿蒙黑体授权不允许修改字体文件，不能切片，所以不作为网页字体下载。
- 开关：`--pa-sans` 是整套字体栈；`--font-geist-sans` 和 `--home-display-latin` 都指向它（包括 next/font 在页面根上重设的地方）。
- 中文标题用 600，不用 700 以上。
- 数字一律 `font-variant-numeric: tabular-nums`。

## 3.1 字号、间距、圆角（只能用这些）
变量在 `styles/palette-a.css`（`--pa-fs-*` / `--pa-sp-*` / `--pa-r-*`），由 `scripts/design-audit.mjs` 检查。

| 字号 | 变量 | 行高 | 用在哪里 |
|---|---|---|---|
| 11 | `--pa-fs-micro` | 14 | 角标、极小的说明。**全站最小字号，不能再小** |
| 12 | `--pa-fs-meta` | 16 | 时间、来源、坐标轴 |
| 13 | `--pa-fs-sub` | 18 | 次要的一行、标签 |
| 15 | `--pa-fs-body` | 22 | 正文、列表里的数值 |
| 17 | `--pa-fs-title` | 24 | 列表行标题、卡片标题 |
| 22 | `--pa-fs-section` | 28 | 区块标题 |
| 28 | `--pa-fs-page` | 34 | 页面大标题、次要的大数字 |
| 40 | `--pa-fs-display` | 44 | 一屏只有一个的主数字（如总资产） |

- 一个页面最多用其中 7 级。字重只用 400 / 500 / 600。
- 12 和 13 都保留：12 只给时间、来源这类附属信息，13 是能读的次要文字。风险说明、规则这类要认真读的字不能用 11。
- 长段中文（说明、协议摘要）可以用 17 当正文。
- 中文不要沿用拉丁字母的负字距。
- 旧值怎么换：6.5–10.5 → 11；11.5 → 12；12.5、13.5 → 13；14–16 → 15；18–19 → 17；20–24 → 22；25 以上 → 28。**40 只给一屏唯一的主数字**，不是把所有大字都放大到 40。未登录的宣传页标题可以例外，要写明原因。
- **间距**：0、2、4、6、8、12、16、20、24、32、48。区块之间 32，卡片内边距 16，同组元素之间 8 或 12，窄屏页边距 20。6 只用在控件内部的几何关系上（例如 56 高的按钮里 44 的圆形箭头，上下各 6）。和安全区、视口单位一起写在 `calc()` 里的不算。
- **圆角**：8（小标签、聚焦框）、12（缩略图、小控件）、22（卡片）、28（面板、大卡）、999（胶囊）；圆形用 50%。4 以下只给细条（进度条、光标）。
- **检查**：`npm run design:audit`。会检查 CSS（包括跨行写的、rem）和 TSX 里的内联样式。
  - 已有的旧值按「文件 + 数值 + 出现次数」记在 `scripts/design-audit-baseline.json` 里。**新出现的值、或者旧值多用了一次**都会报错。
  - 某页改完后，把文件加进脚本里的 `STRICT`，从此这一页必须完全合规，然后跑 `--update` 让基线变小。
  - 基线只能变小：如果有值变多了，`--update` 会拒绝执行，除非加 `--force`。
  - 现在还不检查：行高、字距、CSS 变量的定义值。

## 4. 控件（`components/ui/controls.module.css`）
- 主按钮：短胶囊 + 圆形箭头，宽度跟着文字走，能小就小（和引导页的「登录 / 注册」一样）。普通页面靠左；有数字键盘的交易页居中。不能按时变成灰色、没有箭头。
- 玻璃按钮，圆形图标按钮，输入框（胶囊 + 右侧动作键）。
- 高度 56，页边距 `--page-gutter` 24（窄屏 20）。
- `data-ctl="light" | "dark"` 固定明暗。

## 5. 底部栏与 AI 小助手
- 底部栏保留原形态：胶囊 + 右侧圆球。
- 圆球是纸做的小助手（`lib/paper-buddy.ts`）。球的直径 = 底部栏高度。
- 它显示：未读数、AI 对话状态（听、想、说、出错）、提示结果、空闲和夜间睡觉。
- 其他页面通过 `buddySignal()`（`lib/buddy-signals.ts`）告诉它发生了什么。

## 6. 禁用（"AI 味"）
- 带浅色底的圆角小图标方块；闪光图标 + 青色大写标题。
- 带色块底框 + 图标的错误提示。错误只用一行彩色文字，放在输入框下方，与框内文字对齐。
- 打码的数字（`***`）。
- 承诺收益的文案。
- 旧 W 标志。

## 7. 组件（参数在 `styles/palette-a.css` 的 `--pa-*`；Maison 页面的映射在 `components/maison/maison.module.css` 末尾）
- **卡片**：白纸（深色 `#15181e`），圆角 22，内边距 16，0.5px 细边 + 柔和阴影（`--pa-card*`）。四个角一样圆，左边不加色条。
- **标签 / 筛选**：高 32，胶囊，无边框，浅底 `--pa-fill`，13px/500。选中＝墨色底白字（深色模式反过来，`--pa-sel`）。
- **分段按钮**：高 40，浅底轨道，选中块是白纸 + 细边，13.5px。
- **搜索框**：高 44，浅底，无边框；聚焦时 1.5px 青色描边。旁边的图标按钮同高、同底。
- **列表行**：只用文字；0.5px 分隔线。有真实 logo 才显示 logo；没有 logo 时不放字母方块。
- **涨跌**：只用颜色数字，不加底色块。
- **多个选项的颜色**：`--pa-series-1..4` = 青、墨、灰、沙色。不用彩虹色。
- **状态说明**（如"概念稿 · 未发行"）：一行文字，不加边框和图标。
- **面板**：白纸卡片，圆角 28，从下方弹起。


## 7.1 页面结构与交互
- **一级页面不放标题栏**：顶部直接是这一页的文字菜单（例：资产页"总览 · 持仓 · 收益 · 订单"），固定在状态栏下方。选中项墨色加粗，下面一条 16px 短线，用弹簧动画滑动；切换时回到顶部，并轻微震动。
- **一个数字为主**：总资产这类卡片只放一个大数字 + 一行说明（有持仓时显示盈亏，没有时显示可用余额）。
- **动作跟着数字走**：充值、提现、转账、收款直接放在总额下面，不藏在"+"里。
- **明细默认收起**：点"明细"用弹簧展开，记住用户的选择。
- **没有内容就不画图**：只有现金时不显示资产配置条；空状态只出现一次。
- **不用编号标题**（01 / 02 / 03）：那是杂志排版，金融 App 里只是噪音。
- **按下反馈**：可点的块按下时缩到 0.94–0.97，用回弹曲线 `cubic-bezier(.34, 1.56, .64, 1)`。

- **表单页（充值、提现、转账）**：汇总表只在金额有效后出现，并依次淡入；之前只显示手续费。"最大"放在金额框右边。提示和说明只用一行文字，不加框和图标。
- **钱的动作按钮**：图标 + 文字，不放在带底色的圆圈里；按下时缩小并出现浅底。

## 7.2 交易流程（`components/maison/flow-kit.tsx`）
- **金额优先**：转账、提现、申购都是一页：上面是收款人或产品，中间是最大的金额数字，下面是会"说话"的按钮和我们自己的数字键盘。不弹出系统键盘，页面不会跳动。
- **数字键盘**：左边一列 25% / 50% / 75% / 最大；每按一下轻震；长按删除键清空；电脑上可以直接用实体键盘。
- **会说话的按钮**：按页面从上到下的顺序，说出还缺什么（"填写收款人""输入金额""余额不足""最低 10"），能提交时说"提现 20.00 USDT"。
- **先确认再提交**：点按钮弹出确认面板：金额、收款人/地址、网络、手续费、到账时间、合计；"我已核对"的勾选只在这里出现。
- **安全步骤**：交易密码用我们的键盘，满 6 位自动提交，可选"随机键盘"；验证码同样用键盘，有"粘贴"键，复制后回到页面能自动填入（浏览器允许时），也可以切回系统键盘。
- **成功页**：画出来的对勾（审核中是时钟），金额、回执、"完成 / 再来一笔 / 查看记录"。
- **收款人**：输入框里直接放粘贴、扫码、地址簿图标，下面是最近转过的人（只存在本机）或已保存的地址。
- 交易页全屏打开，不显示底部栏。

## 7.3 顶部栏与状态
- **二级页面没有横幅**：顶部栏透明、没有分隔线、没有拖动条，只留返回/关闭和一个小标题；滚动后用柔和的渐隐，不出现硬边。
- **加载**：与内容同形状的纸色条，慢速光泽。
- **空白**：一张纸卡片，一句标题、一行说明、一个去处，不放图标。
- **出错**：同样只用文字，说明没有提交任何操作，给"重试"和"回首页"。
- **开关**：只有开和关的设置用开关，文字在左、开关在右。

## 8. 动效（`styles/palette-a.css` 的 `--pa-dur-*` / `--pa-ease-*`）
- 按下 120ms，缩到 0.94–0.97，回弹曲线 `cubic-bezier(.34, 1.56, .64, 1)`。
- 状态变化 220ms，`cubic-bezier(.22, 1, .36, 1)`。
- 进入 380ms（上浮 12–16px + 淡入）；面板 460ms 弹簧。
- 出错：数字左右轻抖一次 + 震动；成功：先画圆再画勾。
- 系统开启"减少动态效果"时全部关闭。
