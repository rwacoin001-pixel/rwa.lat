# A-REIT 设计语言 · Paper & Glass（唯一现行规范）

更新：2026-10-27 晚（加入第 4.2 首页、5.4 底部栏 v2、7.4 头像与图片；第 4.1 深色去掉内凹槽）。同日早些时候加入第 3.1 节尺寸规范、通知与 AI、登录与 App 锁。最初版本：2026-10-26。旧的设计规则、设计合同、令牌映射表、HIG 复核和 QA 记录已于同日删除（git 历史可查），以本文为准。
2026-10-26 起是唯一的设计；旧配色、旧页面代码和 `?palette=classic` 开关已删除。

## 1. 气质
冷白纸面 + 一点玻璃。安静、精致、有质感，不靠花哨颜色。参考 Apple 与 Radium 的克制，但不照搬。

## 2. 颜色（`styles/palette-a.css`）
- 浅色：底 `#f5f6f8`，面 `#ffffff`，字 `#0b1220`，次要字 `#5b6472`。
- 深色：底 `#0a0c10`，面 `#14171d`，字 `#f2f4f7`。
- 品牌青：浅色文字用 `#087a67`/`#0a8a73`，深色与标记用 `#19c7aa`。
- 涨跌：浅 `#067a5e` / `#c23b33`（小字也够 4.5:1 对比度），深 `#2fd4a3` / `#ff6b5e`。
- 青色只用在少数地方：选中、主数据、品牌标记。不做大面积底色。

## 3. 字体
- 拉丁字母和数字：**Satoshi**（自托管 `public/fonts/satoshi`，400/500/700/900）。
- 中文：苹果设备用**苹方**；华为、荣耀用本机的**鸿蒙黑体**；其他设备用**思源黑体**（Noto Sans SC，OFL 授权，自托管切片 `public/fonts/noto-sans-sc`，`styles/noto-sans-sc.css`，页面用到哪块才下载）。
  App 自己文案里的字（约 1,200 个）用精简文件 `public/fonts/noto-sans-sc-app`（共约 400 KB）；其他字（名字、新闻、服务器消息）用完整切片。两种文件在同一个字体名下，字符不重叠，所以每个字只下载一个文件。`styles/noto-sans-sc.css` 由 `scripts/fonts/subset_noto_app.py` 生成，**加了新的中文文案后重新跑一次**（不跑也不会缺字，只是新字走完整切片）。
  鸿蒙黑体授权不允许修改字体文件，不能切片，所以不作为网页字体下载。
- 开关：`--pa-sans` 是整套字体栈；`--font-geist-sans` 和 `--home-display-latin` 都指向它（包括 next/font 在页面根上重设的地方）。
- 字重：中文用 400 / 500 / 600（苹方、鸿蒙黑体、思源都有 600）。拉丁字母和数字用 400 / 500 / 700：**Satoshi 没有 600**，写 600 时浏览器会用 700 的文件。不用 700 以上（首页现有 730、750 两处，迁移时改掉）。
- 数字一律 `font-variant-numeric: tabular-nums`。

## 3.1 字号、间距、圆角（只能用这些）
变量在 `styles/palette-a.css`（`--pa-fs-*` / `--pa-sp-*` / `--pa-r-*`），由 `scripts/design-audit.mjs` 检查。

| 字号 | 变量 | 行高 | 用在哪里 |
|---|---|---|---|
| 11 | `--pa-fs-micro` | 14 | 角标、极小的说明。**全站最小字号，不能再小** |
| 12 | `--pa-fs-meta` | 16 | 时间、来源、坐标轴 |
| 13 | `--pa-fs-sub` | 18 | 次要的一行、标签 |
| 15 | `--pa-fs-body` | 22 | 正文、列表里的数值 |
| 17 | `--pa-fs-title` | 24 | 列表行标题、卡片标题 |
| 22 | `--pa-fs-section` | 28 | 区块标题 |
| 28 | `--pa-fs-page` | 34 | 页面大标题、次要的大数字 |
| 40 | `--pa-fs-display` | 44 | 一屏只有一个的主数字（如总资产） |

- 一个页面最多用其中 7 级。字重见第 3 节。
- 12 和 13 都保留：12 只给时间、来源这类附属信息，13 是能读的次要文字。风险说明、规则这类要认真读的字不能用 11。
- 长段中文（说明、协议摘要）可以用 17 当正文。
- 中文不要沿用拉丁字母的负字距。
- 旧值怎么换：6.5–10.5 → 11；11.5 → 12；12.5、13.5 → 13；14–16 → 15；18–19 → 17；20–24 → 22；25 以上 → 28。**40 只给一屏唯一的主数字**，不是把所有大字都放大到 40。未登录的宣传页标题可以例外，要写明原因。
- **间距**：0、2、4、6、8、12、16、20、24、32、48。区块之间 32，卡片内边距 16，同组元素之间 8 或 12，窄屏页边距 20。6 只用在控件内部的几何关系上（例如 56 高的按钮里 44 的圆形箭头，上下各 6）。和安全区、视口单位一起写在 `calc()` 里的不算。
- **圆角**：8（小标签、聚焦框）、12（缩略图、小控件）、22（卡片）、28（面板、大卡）、999（胶囊）；圆形用 50%。4 以下只给细条（进度条、光标）。
- **检查**：`npm run design:audit`。会检查 CSS（包括跨行写的、rem）和 TSX 里的内联样式。
  - 已有的旧值按「文件 + 数值 + 出现次数」记在 `scripts/design-audit-baseline.json` 里。**新出现的值、或者旧值多用了一次**都会报错。
  - 某页改完后，把文件加进脚本里的 `STRICT`，从此这一页必须完全合规，然后跑 `--update` 让基线变小。
  - 基线只能变小：如果有值变多了，`--update` 会拒绝执行，除非加 `--force`。
  - 现在还不检查：行高、字距、CSS 变量的定义值。

## 4. 控件（`components/ui/controls.module.css`）
- 主按钮：短胶囊 + 圆形箭头，宽度跟着文字走，能小就小（和引导页的「登录 / 注册」一样）。普通页面靠左；有数字键盘的交易页居中。不能按时变成灰色、没有箭头。
- 玻璃按钮，圆形图标按钮，输入框（胶囊 + 右侧动作键）。
- 高度 56，页边距 `--page-gutter` 24（窄屏 20）。
- `data-ctl="light" | "dark"` 固定明暗。

## 4.1 实体按钮质感（2026-10-27 起）
浅色是**白瓷片**，深色是**石墨片**。变量是 `--pa-tile-*` 和 `--pa-well-*`（`styles/palette-a.css`）。
- 质感由四层组成（都在 `--pa-tile-bg` / `--pa-tile-shadow` 里）：
  1. 145° 渐变：左上亮，右下暗。
  2. 斜面：左上一道 1px 亮边，右下一道 1px 暗边（inset 阴影）。
  3. 投影：一道贴近的短影 + 一道往右下落的宽柔影。
  4. 图标浮雕：`--pa-tile-glyph`，浅色是图标下方 1px 白线，深色是图标上方 1px 黑线。
- **深色模式不放内凹圆槽**（2026-10-27 去掉）：在小方片里再套一个深色圆，看起来像中间"一圈黑"，脏。凹槽只给 AI 输入框用。

- **只用在这三类地方**：
  - 资产卡下面的四个钱的动作（充值、提现、转账、收款）：圆角方片，圆角是边长的 22%，图标 22px，文字放在方片下面。
  - 主按钮：浅色是墨色胶囊加顶边高光，深色是浅灰胶囊。
  - AI 输入框：做成**凹进去的槽**，表示"在这里输入"。发送键是凸起的小圆片。
- **不要用在**列表、卡片、标签、分段按钮上。每样东西都凸起来，页面会变重，能点和不能点也分不清。
- **按下**：缩到 0.95，阴影变浅，像真的被按下去（120ms，回弹曲线）。
- **对比度**：图标和文字仍然要达到 4.5:1，不能靠阴影来表示"能点"。
- **性能**：一屏里最多 8 个实体按钮。滚动的列表里不要放带多层阴影的元素。
- **减少透明度**：系统开了"减少透明度"或"增强对比度"时，去掉渐变，只留一条 0.5px 边线。

## 4.2 首页（登录后，`components/screens/P04-HomeMaison.tsx`，v2）
从上到下：
1. **顶部栏**：左边 A-REIT 标志（32px 白瓷小片，下拉刷新时青色门板会打开），右边月亮（主题切换）和头像。上滑隐藏，下拉出现。
2. **问候语**：一行 13px 次要字，「早上好 · 10月27日 周二」（夜深了 0–5 点 / 早上好 5–12 / 下午好 12–18 / 晚上好 18–24）。
3. **资产卡**（`components/home/HomeAssetCard.tsx`）：
   - 「总资产 · USDT」+ 眼睛（隐藏余额，记在 `rwa.home.hide-balance`）+「明细 >」。
   - 一个 40px 主数字。本次打开 App 第一次出现时跳数一次（600ms，`rwa.home.counted`）。
   - 主数字右边一条 7 天走势线（最宽 96px，见下方「走势线」）。隐藏余额时一起隐藏。
   - 下面一行：今日收益（按今天入账算，见下）和可用余额。
   - 有充值在路上时，多一行「充值中 …」。
   - 四个实体按钮：充值、提现、转账、收款（第 4.1 节）。
   - 余额为 0：不显示 0.00 和四个按钮，改成一句邀请 +「去充值」主按钮。
   - 加载中：同形状的纸色条。
4. **问 AI**：凹进去的输入槽 + 凸起的发送键。点一下进入 AI，问题带过去（`rwa.ai.prefill`）。
5. **邀请卡**（`components/home/HomeReferral.tsx`）：已邀请的人的头像（最多 4 个 + `+N`），没有时是 3 个空槽 + 「+」；右边一个数字（可领取，或累计已赚）；按钮「邀请好友 →」，有可领时多一个「领取」。后台关闭奖励时整张卡不出现。
6. **为你推荐 / 行情 / 预测市场**：每块一个 22px 标题，进入视口时上浮淡入。行情的数字用逐位滚动（`RollingText`）。行情的两张大卡下面各有一条全宽走势线，下面的列表每行有一条 56px 的。
7. **社区**：无限滚动的信息流。滑到顶部时，社区的分类标签吸顶，变成菜单。
- **今日收益**的算法（后端 `GET /v1/portfolio/summary`）：新加坡时间 0 点以来入账的量化日结、推荐奖励、收益发放（扣掉冲正），加上今天结算的预测（赔付 − 本金）。不按市值快照算，因为大部分用户没有快照。
- **走势线**（`components/home/Sparkline.tsx`）：数据本身就是装饰。
  - 一条 1.5px 的灰线（`--q-dim2`），不填色、不画坐标、不写数字。进入时从左往右画出来（600ms），末端出现一个 4px 小圆点，表示「今天」。
  - 行情：圆点用当天涨跌色。资产卡：圆点是中性灰，因为总资产也会因为充值而上涨，用绿色会让人误以为是赚的。
  - 少于 2 个点、或 7 天完全没变化时不画（一条平线只是噪音）。
  - 数据：行情来自 `GET /v1/market-context` 每条报价的 `spark`（最近 7 个日收盘价，Yahoo / OKX，缓存 1 小时，最多等 1.5 秒，取不到就是 null，不影响报价）。资产卡来自 `GET /v1/portfolio/summary` 的 `sparkAtomic`（过去 6 天每天 24 点的总资产 + 现在；用账本倒推，是准确值）。
- 未登录用户仍然看旧的宣传首页。
- 动效顺序：卡片上浮 → 四个按钮依次弹出（间隔 0.04s，0.08–0.2s）→ 下面的区块进入视口时再出现。

## 5. 底部栏与 AI 小助手
- 底部栏保留原形态：胶囊 + 右侧圆球。
- 圆球是纸做的小助手（`lib/paper-buddy.ts`）。球的直径 = 底部栏高度。
- 它显示：未读数、AI 对话状态（听、想、说、出错）、提示结果、空闲和夜间睡觉。
- 其他页面通过 `buddySignal()`（`lib/buddy-signals.ts`）告诉它发生了什么。
- 点圆球 = 打开 AI。

## 5.4 底部栏 v2（`components/h5/BottomDock.tsx`、`dock-v2.module.css`）
- 三层：外盘 56 高（内边距 2）→ 凹槽 52（内边距 2）→ 选中胶囊 48。没有光晕（试过，贴不住按钮，去掉了）。
- **只有选中的那一项显示文字**，其他只有图标。选中项变宽：它的 flex 是 1.9，其他是 1，所以英文这种长标签也放得下。胶囊宽度 = `(100% - 4px) × 1.9 / 总份数`，位置用 `translateX` 跟过去，弹簧动画。
- 文字最长 7em，再长就省略号。改文案时在英文下检查一次。
- 往上滑时收缩成只剩选中那一项的小胶囊，往下滑恢复。
- 浅色模式下底部条保持浅色（用户主要用浅色）。

## 5.1 通知（2026-10-26 起）
- **通知只在一个地方**：AI 输入框上方的一条小标签（`components/maison/AiNoticeTray.tsx`）。它和输入框连在一起，像从输入框里长出来一样。
  - 收起时只有一行：小圆点 + 最新一条 + 时间 + `+N`。有多条时每 4.5 秒换下一条。
  - 展开后显示最近 5 条，每条可以打开，也可以「问 AI」。下面有「全部已读」「让 AI 总结」。
  - 用户开始打字或说话时，标签收起。
- 圆球上显示未读数。其他页面**不放铃铛**，头像上也不放未读数。「我的」页面里有一行「通知」，用来看全部通知。
- 通知按手机语言显示（服务器同时存中文和英文，`payload.i18n`）。

## 5.2 AI 对话的动效
- 回答像打字一样逐字出现，后面跟一个青色光标；点一下就直接显示全文。读屏软件一次读完整段。
- 自己发的消息带一点弹性从下往上飞入。等待时的占位条上有一道光扫过。
- 输入框获得焦点时轻轻浮起 2px；有文字时，发送按钮从 0.86 弹到 1。
- 系统开启"减少动态效果"时全部关闭。

## 5.3 登录与 App 锁
- 语言：手机语言优先，其次才看所在国家；用户在 App 里手动选过的语言最优先。
- 在这台手机上用 Passkey 登录过的账号，打开登录页时直接进入 Passkey 这一步（安卓自动弹出，苹果要点一下）。
- 安装到桌面的 App，并且在这台手机上用过 Passkey：每次重新打开、或离开超过 5 分钟回来时，先显示锁屏（「欢迎回来」+ 打码的邮箱 + 「解锁」）。在浏览器里打开则是一天没用才锁。
- 登录状态随使用自动延长（离最后一次使用 30 天，总共最多 180 天）。动钱的操作另外验证身份。

## 6. 禁用（"AI 味"）
- **带彩色浅底**的圆角小图标方块（青色、蓝色、紫色底，这是 AI 味）；闪光图标加青色大写标题。中性材质的实体按钮不在此列，见 4.1 节。
- 带色块底框 + 图标的错误提示。错误只用一行彩色文字，放在输入框下方，与框内文字对齐。
- 打码的数字（`***`）。
- 承诺收益的文案。
- 旧 W 标志。

## 7. 组件（参数在 `styles/palette-a.css` 的 `--pa-*`；Maison 页面的映射在 `components/maison/maison.module.css` 末尾）
- **卡片**：白纸（深色 `#15181e`），圆角 22，内边距 16，0.5px 细边 + 柔和阴影（`--pa-card*`）。四个角一样圆，左边不加色条。
- **标签 / 筛选**：高 32，胶囊，无边框，浅底 `--pa-fill`，13px/500。选中＝墨色底白字（深色模式反过来，`--pa-sel`）。
- **分段按钮**：高 40，浅底轨道，选中块是白纸 + 细边，13.5px。
- **搜索框**：高 44，浅底，无边框；聚焦时 1.5px 青色描边。旁边的图标按钮同高、同底。
- **列表行**：只用文字；0.5px 分隔线。有真实 logo 才显示 logo；没有 logo 时不放字母方块。
- **涨跌**：只用颜色数字，不加底色块。
- **多个选项的颜色**：`--pa-series-1..4` = 青、墨、灰、沙色。不用彩虹色。
- **状态说明**（如"概念稿 · 未发行"）：一行文字，不加边框和图标。
- **面板**：白纸卡片，圆角 28，从下方弹起。

## 7.1 页面结构与交互
- **一级页面不放标题栏**：顶部直接是这一页的文字菜单（例：资产页"总览 · 持仓 · 收益 · 订单"），固定在状态栏下方。选中项墨色加粗，下面一条 16px 短线，用弹簧动画滑动；切换时回到顶部，并轻微震动。
- **一个数字为主**：总资产这类卡片只放一个大数字 + 一行说明（有持仓时显示盈亏，没有时显示可用余额）。
- **动作跟着数字走**：充值、提现、转账、收款直接放在总额下面，不藏在"+"里。
- **明细默认收起**：点"明细"用弹簧展开，记住用户的选择。
- **没有内容就不画图**：只有现金时不显示资产配置条；空状态只出现一次。
- **不用编号标题**（01 / 02 / 03）：那是杂志排版，金融 App 里只是噪音。
- **按下反馈**：可点的块按下时缩到 0.94–0.97，用回弹曲线 `cubic-bezier(.34, 1.56, .64, 1)`。

- **表单页（充值、提现、转账）**：汇总表只在金额有效后出现，并依次淡入；之前只显示手续费。"最大"放在金额框右边。提示和说明只用一行文字，不加框和图标。
- **钱的动作按钮**：图标 + 文字，不放在带底色的圆圈里；按下时缩小并出现浅底。

## 7.2 交易流程（`components/maison/flow-kit.tsx`）
- **金额优先**：转账、提现、申购都是一页：上面是收款人或产品，中间是最大的金额数字，下面是会"说话"的按钮和我们自己的数字键盘。不弹出系统键盘，页面不会跳动。
- **数字键盘**：左边一列 25% / 50% / 75% / 最大；每按一下轻震；长按删除键清空；电脑上可以直接用实体键盘。
- **会说话的按钮**：按页面从上到下的顺序，说出还缺什么（"填写收款人""输入金额""余额不足""最低 10"），能提交时说"提现 20.00 USDT"。
- **先确认再提交**：点按钮弹出确认面板：金额、收款人/地址、网络、手续费、到账时间、合计；"我已核对"的勾选只在这里出现。
- **安全步骤**：交易密码用我们的键盘，满 6 位自动提交，可选"随机键盘"；验证码同样用键盘，有"粘贴"键，复制后回到页面能自动填入（浏览器允许时），也可以切回系统键盘。
- **成功页**：画出来的对勾（审核中是时钟），金额、回执、"完成 / 再来一笔 / 查看记录"。
- **收款人**：输入框里直接放粘贴、扫码、地址簿图标，下面是最近转过的人（只存在本机）或已保存的地址。
- 交易页全屏打开，不显示底部栏。

## 7.3 顶部栏与状态
- **二级页面没有横幅**：顶部栏透明、没有分隔线、没有拖动条，只留返回/关闭和一个小标题；滚动后用柔和的渐隐，不出现硬边。
- **加载**：与内容同形状的纸色条，慢速光泽。
- **空白**：一张纸卡片，一句标题、一行说明、一个去处，不放图标。
- **出错**：同样只用文字，说明没有提交任何操作，给"重试"和"回首页"。
- **开关**：只有开和关的设置用开关，文字在左、开关在右。

## 8. 动效（`styles/palette-a.css` 的 `--pa-dur-*` / `--pa-ease-*`）
- 按下 120ms，缩到 0.94–0.97，回弹曲线 `cubic-bezier(.34, 1.56, .64, 1)`。
- 状态变化 220ms，`cubic-bezier(.22, 1, .36, 1)`。
- 进入 380ms（上浮 12–16px + 淡入）；面板 460ms 弹簧。
- 出错：数字左右轻抖一次 + 震动；成功：先画圆再画勾。
- 系统开启"减少动态效果"时全部关闭。
- **跳数（数字从 0 滚到真实值）**：
  - 只用在**一屏唯一的主数字**上（例如总资产），而且只在这次打开 App 后它第一次出现时跳一次。
  - 最长 600ms，先快后慢（`--pa-ease-out`）。
  - 读屏软件直接读最终数字（动画部分 `aria-hidden`）。
  - 系统开了"减少动态效果"时直接显示最终数字。
  - 数据还没加载好时不跳，加载完再跳。不能从 0 开始跳，然后停在一个假的 0 上。
- **会实时变化的数字**（行情、涨跌幅、余额刷新）不从 0 跳。改用**逐位滚动**：只有变了的那几位，上下滚动到新值（220ms）。涨的时候数字闪一下涨色，跌的时候闪一下跌色，400ms 后褪回原色。
- 首页现在的 `CountUp` 用的是 1.8 秒，用在了市场总值这种次要数字上，不合规，迁移时改掉。
