## 1. 气质
冷白纸面 + 一点玻璃。安静、精致、有质感，不靠花哨颜色。参考 Apple 与 Radium 的克制，但不照搬。

## 2. 颜色（`styles/palette-a.css`）
- 浅色：底 `#ffffff`（2026-10-28 起全站纯白，`--pal-light-bg`），面 `#ffffff`（卡片靠细边和阴影分开，`--pa-card-shadow`），字 `#0b1220`，次要字 `#5b6472`。
- 深色：底 `#0a0c10`，面 `#14171d`，字 `#f2f4f7`。
- 品牌青：浅色文字用 `#087a67`/`#0a8a73`，深色与标记用 `#19c7aa`。
- 涨跌：浅 `#067a5e` / `#c23b33`（小字也够 4.5:1 对比度），深 `#2fd4a3` / `#ff6b5e`。
- 青色只用在少数地方：选中、主数据、品牌标记。不做大面积底色。

## 3. 字体
- 拉丁字母和数字：**Satoshi**（自托管 `public/fonts/satoshi`，400/500/700/900）。
- 中文：苹果设备用**苹方**；华为、荣耀用本机的**鸿蒙黑体**；其他设备用**思源黑体**（Noto Sans SC，OFL 授权，自托管切片 `public/fonts/noto-sans-sc`，`styles/noto-sans-sc.css`，页面用到哪块才下载）。
  App 自己文案里的字（约 1,200 个）用精简文件 `public/fonts/noto-sans-sc-app`（共约 400 KB）；其他字（名字、新闻、服务器消息）用完整切片。两种文件在同一个字体名下，字符不重叠，所以每个字只下载一个文件。`styles/noto-sans-sc.css` 由 `scripts/fonts/subset_noto_app.py` 生成，**加了新的中文文案后重新跑一次**（不跑也不会缺字，只是新字走完整切片）。
  鸿蒙黑体授权不允许修改字体文件，不能切片，所以不作为网页字体下载。
- 开关：`--pa-sans` 是整套字体栈；`--font-geist-sans` 和 `--home-display-latin` 都指向它（包括 next/font 在页面根上重设的地方）。
- 字重：中文用 400 / 500 / 600（苹方、鸿蒙黑体、思源都有 600）。拉丁字母和数字用 400 / 500 / 700：**Satoshi 没有 600**，写 600 时浏览器会用 700 的文件。不用 700 以上（首页现有 730、750 两处，迁移时改掉）。
- 数字一律 `font-variant-numeric: tabular-nums`。

## 3.1 字号、间距、圆角（只能用这些）
变量在 `styles/palette-a.css`（`--pa-fs-*` / `--pa-sp-*` / `--pa-r-*`），由 `scripts/design-audit.mjs` 检查。

| 字号 | 变量 | 行高 | 用在哪里 |
|---|---|---|---|
| 11 | `--pa-fs-micro` | 14 | 角标、极小的说明。**全站最小字号，不能再小** |
| 12 | `--pa-fs-meta` | 16 | 时间、来源、坐标轴 |
| 13 | `--pa-fs-sub` | 18 | 次要的一行、标签 |
| 15 | `--pa-fs-body` | 22 | 正文、列表里的数值 |
| 17 | `--pa-fs-title` | 24 | 列表行标题、卡片标题 |
| 22 | `--pa-fs-section` | 28 | 区块标题 |
| 28 | `--pa-fs-page` | 34 | 页面大标题、次要的大数字 |
| 40 | `--pa-fs-display` | 44 | 一屏只有一个的主数字（如总资产） |

- 一个页面最多用其中 7 级。字重见第 3 节。
- 12 和 13 都保留：12 只给时间、来源这类附属信息，13 是能读的次要文字。风险说明、规则这类要认真读的字不能用 11。
- 长段中文（说明、协议摘要）可以用 17 当正文。
- 中文不要沿用拉丁字母的负字距。
- 旧值怎么换：6.5–10.5 → 11；11.5 → 12；12.5、13.5 → 13；14–16 → 15；18–19 → 17；20–24 → 22；25 以上 → 28。**40 只给一屏唯一的主数字**，不是把所有大字都放大到 40。未登录的宣传页标题可以例外，要写明原因。
- **间距**：0、2、4、6、8、12、16、20、24、32、48。区块之间 32，卡片内边距 16，同组元素之间 8 或 12，窄屏页边距 20。6 只用在控件内部的几何关系上（例如 56 高的按钮里 44 的圆形箭头，上下各 6）。和安全区、视口单位一起写在 `calc()` 里的不算。
- **圆角**：8（小标签、聚焦框）、12（缩略图、小控件）、22（卡片）、28（面板、大卡）、999（胶囊）；圆形用 50%。4 以下只给细条（进度条、光标）。
- **检查**：`npm run design:audit`。会检查 CSS（包括跨行写的、rem）和 TSX 里的内联样式。
  - 已有的旧值按「文件 + 数值 + 出现次数」记在 `scripts/design-audit-baseline.json` 里。**新出现的值、或者旧值多用了一次**都会报错。
  - 某页改完后，把文件加进脚本里的 `STRICT`，从此这一页必须完全合规，然后跑 `--update` 让基线变小。
  - 基线只能变小：如果有值变多了，`--update` 会拒绝执行，除非加 `--force`。
  - 现在还不检查：行高、字距、CSS 变量的定义值。

## 4.1 实体按钮质感（2026-10-27 起）
浅色是**白瓷片**，深色是**石墨片**。变量是 `--pa-tile-*` 和 `--pa-well-*`（`styles/palette-a.css`）。
- 质感由四层组成（都在 `--pa-tile-bg` / `--pa-tile-shadow` 里）：
  1. 145° 渐变：左上亮，右下暗。
  2. 斜面：左上一道 1px 亮边，右下一道 1px 暗边（inset 阴影）。
  3. 投影：一道贴近的短影 + 一道往右下落的宽柔影。
  4. 图标浮雕：`--pa-tile-glyph`，浅色是图标下方 1px 白线，深色是图标上方 1px 黑线。
- **深色模式不放内凹圆槽**（2026-10-27 去掉）：在小方片里再套一个深色圆，看起来像中间"一圈黑"，脏。凹槽只给 AI 输入框用。

- **用在这些地方**（2026-10-27 起放宽：用户喜欢白瓷，动作按钮都可以用）：
  - 资产卡下面的四个钱的动作（充值、提现、转账、收款）：圆角方片，圆角是边长的 22%，图标 22px，文字放在方片下面。
  - 主按钮：浅色是墨色胶囊加顶边高光，深色是浅灰胶囊。
  - AI 输入框：做成**凹进去的槽**，表示"在这里输入"。发送键是凸起的小圆片。
  - 次要的动作按钮：「领取」、顶部「下载 App」小胶囊、卡片角上的进入小圆片。
  - 分段按钮：轨道是凹槽，选中块是白瓷片（首页「宏观 / 黄金现货」）。
- **不要用在**卡片本身、列表行、文字链接、标签上。每样东西都凸起来，就没有一个是突出的，能点和不能点也分不清。
- **按下**：缩到 0.95，阴影变浅，像真的被按下去（120ms，回弹曲线）。
- **对比度**：图标和文字仍然要达到 4.5:1，不能靠阴影来表示"能点"。
- **性能**：一屏里最多 8 个实体按钮。滚动的列表里不要放带多层阴影的元素。
- **减少透明度**：系统开了"减少透明度"或"增强对比度"时，去掉渐变，只留一条 0.5px 边线。

     - 分段按钮是凹槽 + 白瓷选中块；两张大卡是白纸卡片，手指按住时有一团青色的光跟着手指（Spotlight）。切换标签时两张卡先后进入。数字用逐位滚动（`RollingText`）。

- **走势线**（`components/home/Sparkline.tsx`）：数据本身就是装饰。
  - 一条 1.5px 的**平滑曲线**，灰色（`--m-faint`），不画坐标、不写数字、**没有圆点**（用户觉得一根线带一个点不好看）。进入时从左往右画出来（900ms）。行情大卡里曲线下面有一层很淡的灰色渐变填充。

- 动效顺序：卡片上浮 → 四个按钮依次弹出（间隔 0.04s，0.08–0.2s）→ 下面的区块进入视口时再出现。

## 4.3 安装（2026-10-27 起）
- **iPhone**：必须用主屏幕版（PWA），安装门负责（`components/ios-install-gate.tsx`）。
- **安卓**：所有浏览器（包括 Chrome）都下载 App，不再提供"添加到主屏幕"。理由：只有一种装法、一份教程（安装视频讲的就是 App）；App 能用系统分享、保存海报到相册，这对邀请很重要。规则在 `needsAndroidApp()`（`components/home/install-env.ts`）。
- **微信 / 其他 App 内的浏览器**：先提示在浏览器打开。

## 8. 动效（`styles/palette-a.css` 的 `--pa-dur-*` / `--pa-ease-*`）
- 按下 120ms，缩到 0.94–0.97，回弹曲线 `cubic-bezier(.34, 1.56, .64, 1)`。
- 状态变化 220ms，`cubic-bezier(.22, 1, .36, 1)`。
- 进入 380ms（上浮 12–16px + 淡入）；面板 460ms 弹簧。
- 出错：数字左右轻抖一次 + 震动；成功：先画圆再画勾。
- 系统开启"减少动态效果"时全部关闭。
- **滑动渐入**（2026-10-28，参考苹果官网，`components/maison/useScrollReveal.ts`）：每个页面里，第一屏以下的内容块先稍微靠下、透明，滑到它时上升 24px 并淡入（0.8–0.9 秒，长尾缓出）。第一屏的内容不等，直接出现；固定或吸附的部分（底部按钮、吸顶菜单）不动。首页的区块用同样手感的 `Rise`。
- **底部小球**：固定在右下角，大小不变；底部栏收缩、展开、下拉刷新时都不会带着它移动；滑动页面时它照常动，不停住。
- **跳数（数字从 0 滚到真实值）**：
  - 只用在**一屏唯一的主数字**上（例如总资产），而且只在这次打开 App 后它第一次出现时跳一次。
  - 最长 600ms，先快后慢（`--pa-ease-out`）。
  - 读屏软件直接读最终数字（动画部分 `aria-hidden`）。
  - 系统开了"减少动态效果"时直接显示最终数字。
  - 数据还没加载好时不跳，加载完再跳。不能从 0 开始跳，然后停在一个假的 0 上。
- **会实时变化的数字**（行情、涨跌幅、余额刷新）不从 0 跳。改用**逐位滚动**：只有变了的那几位，上下滚动到新值（220ms）。涨的时候数字闪一下涨色，跌的时候闪一下跌色，400ms 后褪回原色。
- 首页现在的 `CountUp` 用的是 1.8 秒，用在了市场总值这种次要数字上，不合规，迁移时改掉。
