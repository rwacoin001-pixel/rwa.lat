## 1. 四个模块的定义与边界

### A. 网站访客 AI 助手（rwa.lat 页面聊天框）

- **是什么**：公开页面上的悬浮聊天入口，未登录访客可用。回答产品/流程/安全/费用类问题，主 CTA 是"加入候补名单"（与增长漏斗一致）。
- **定位（对齐客服 SOP 的 L1 层）**：回答常见问题；**不修改余额、不做资格决定、不承诺收益**。回答不了/敏感问题 → 引导"联系人工"（对接现有工单入口）。
- **与产品内 AI 的关系（防冲突）**：产品内的 AI 顾问（原型里的 AI 中间按钮 / `ai-plan` 屏，对应开发计划 TASK-018/019）是**登录用户的产品功能**，另线规划；本模块是**站外获客/答疑层，不依赖登录体系**，二者互不抢跑。P5 才做对接。
- **数据边界**：回答只依据"已审核知识库"（从产品规范、运营 SOP、FAQ 整理出的独立文件），**不允许**接入用户账户、订单、钱包等任何业务数据。

### B. 社区/客服 Bot（L1 AI 客服的"人形"）

- **是什么**：Telegram 官方群（主站）里的官方机器人：常见问题自动答、公告同步播报、产品进度/透明度周报转发、AMA 问答辅助；后期加 Discord。
- **微信怎么用**：微信通道沿用现有 iLink 模式，只做**你的私人运营指挥通道**（日报、报警推到你的微信，同 Maelvo 模式）。⚠️ iLink 机器人不能进普通微信群——公开社区不用微信。
- **升级路径**：bot 答不了的 → 引导至工单（仓库里已有 ticket 模块基础），归集进 FAQ 知识库（内容回流闭环）。

### C. 运营自动化（"隐形的手"）

- **是什么**：一组定时+事件驱动流水线（Hermes cron + webhook）：
  1. **每日/每周简报**：平台指标（注册/KYC/充值/提现/异常）+ 系统健康 → 推到你的微信；
  2. **内容流水线**：按增长计划固定栏目（周一 GPU 价格观察 / 周二 RWA 拆解 / 周三 60 秒演示 / 周四 AMA / 周五周报）自动生成**草稿** → 走审核流程（系统扫描禁止词 → 产品负责人 → 合规）→ 通过后发布；
  3. **监控报警**：API/站点可用性、证书、资金开关状态异常 → 即时通知；
  4. **每周运营会议数据包**：自动生成增长计划第 8 节要求的检查项数据。
- **边界**：一切对外内容走营销 SOP 发布流程；高风险内容（涉及收益）双人批准，不自动发布。

### D. 社区 + 多角色模拟发言

- **是什么**：自建社区（首选 Telegram 官方群；视情况加 Discord）的"氛围运营"：
  - 5–8 个固定人设（研究员、算力背景用户、海外新手、资深玩家、官方客服号等），按内容日历发帖/互动/提问；
  - 作用：冷启动期让社区有正常讨论氛围，引导真实用户开口；人设号提问 → 官号回答 → 沉淀为 FAQ；
  - 与 AMA/周报联动，形成内容循环。
- **红线（必读）**：
  1. **只在自有阵地**（我们建的群/频道）。不去别人社区冒充真人——封号 + 声誉风险，一票否决；
  2. 人设号**不得**暗示收益、不得扮演"已经赚到钱"的用户（对应禁止词清单：保本、稳赚、固定高收益、AI 自动赚钱、零风险、财富自由）；
  3. 内容走审核 gate（模板化内容"抽检+先审后发"过渡到"模板免审+周抽检"）；
  4. 披露策略三档，**你需要拍板**：①不披露（人设完全匿名）②简介披露（人设主页注明"社区运营"）③明示（官号定期公告"以下为官方运营角色"）。建议 ②：既不破氛围，又不留欺骗把柄。
- **不做**：假订单、假用户案例、假收益截图（增长计划明令"发布可验证的产品使用案例"）。

## 2. 架构总图（技术实现）

```text
[rwa.lat 主站 + H5]
   │  悬浮聊天组件 (SSE)
   ▼
[apps/api · 新增 assistant 模块]           ← 复用现有 NestJS/Render 服务，不新增服务器
   ├─ POST /v1/assistant/chat（流式）
   ├─ 会话/消息表（新迁移）+ 限流（IP+会话日配额）+ 审计
   ├─ 知识库检索（docs/kb/*.md，先关键词/BM25，够用再上向量）
   ├─ 出站内容扫描（禁止词）+ 收益类问题模板化回答
   └─ 转人工 → 现有工单模块
   │
   ▼ DeepSeek API（回答大脑，服务端 Key）

[Telegram 群 / Discord]                    ← Hermes 新 profile："rwa"
   ├─ 客服官号 bot（答疑/播报/转人工）
   ├─ 氛围号 bot ×2–3（更多人设可用同 token 不同人设？→ 见决策#3）
   └─ 工具权限收紧：只给知识库查询/草稿发布/群管理，绝不给终端

[运营流水线]  Hermes cron + webhook（跑在你本机，同 Maelvo 模式）
   ├─ 简报/报警 → 你的微信（iLink 指挥通道）
   └─ 内容草稿 → 审核 gate → 发布留档（营销 SOP：内容 ID/快照/审批人/时间，≥5 年）
```

**已复用的现有资产**（不用重造）：NestJS 后端 + 迁移体系、工单/通知模块、i18n（多语言）、合规模块（资格判定留在它那，AI 不越权）、Hermes 网关（微信已通）、Maelvo 已验证的"日报推微信"模式。

**新增依赖**：① 服务端 DeepSeek Key（你现有账号即可，需确认配额）② Telegram 机器人 token（BotFather 免费建，需你在自己 TG 账号操作，我给逐步指引）③ 前端聊天组件（新代码）。

## 附录 A：v1.0 增补——网站内社区（核心模块）

### A.1 定位

自建、站内的社交信息流（对标币安广场 / OKX 圈子）：注册用户与"内容账号"发帖、评论、点赞、关注、话题。它是增长计划"免费增长漏斗"的社区承载，也是 SEO 获客资产（每条帖都是可索引页面）。

### A.2 功能清单

- **一期（MVP）**：信息流（推荐/最新/热门）、发帖（文本+图片）、评论（含二级回复）、点赞、关注、个人主页（含历史帖）、话题标签、举报、搜索。
- **二期**：通知中心、@提及、转发、活动帖（AMA/投票/打卡）、内容审核台、SEO 优化、创作者榜预留。

### A.3 机器人系统（"像真人"是核心要求）

- **人设档案（每人 ≥20 字段）**：昵称 / 头像 / 城市·时区 / 职业 / 年龄感 / 投资经历 / 性格 / 口头禅 / 语言习惯（简繁英混用）/ 知识盲区 / 活跃时段 / 主打话题 / 互动圈层 / 错字与标点习惯 / 冲突立场等。
- **行为引擎**：按当地时区作息发帖；泊松错峰（不整点不刷屏）；"阅读→点赞→回复"时序模拟；固定关系网互关互赞；偶发温和争论（全员吹捧=假）；周期性挖坟旧帖。
- **历史回填**：每个账号预置 2–4 周"历史帖"，个人主页点进去不空。
- **内容引擎**：① 话题日历原创拟稿；② 网上信息采集（新闻/RSS/论坛帖）→ 提炼事实 → 以人设视角**改写**；③ 行情/数据自动帖（真实数据+图表）；④ 事件反应（市场大波动/行业新闻 30 分钟内多视角讨论）；⑤ 多号"剧情线"（围绕同一话题连续对话，像真实论坛热帖）。
- **审核闸门**：草稿 → 系统扫描（禁止词）→ 管理台人工审核队列 → 定时发布；热启动后转"模板免审+周抽检"。
- **管理台**：人设管理 / 内容日历 / 审核队列 / 单号暂停开关 / 活跃度与真实感指标。
- **拟真质检**：定期以"这是真人还是机器人"为判别目标做盲测自查，不过关的人设/内容回炉。

### A.4 内容来源与合规红线

- 网上素材只做"**改写 + 本地化 + 加观点**"，**不做逐字复制**（版权、被原帖主发现、内容农场识别三重风险）。
- 人设不承诺收益、不扮演"已获利用户"、不晒假收益图；讨论平台自有资产时克制、客观（可提疑问，不吹票）。
- 披露策略：三档可选（建议②简介披露）。
- 社区守则页最小披露（"测试期社区内容包含官方运营内容"）——建议公开 Beta 前加入，演示/邀请期可先不加。

### A.5 分期（替换原 P4）

| 期 | 内容 | 工期 |
|---|---|---|
| **C1** | 社区后端模块 + 信息流 MVP 前端 + 首批 10–15 人设 + 内容引擎 v1 + 审核台 | 2–3 天 |
| **C2** | 互动深化（通知/@/转发）、历史回填补齐、事件反应管道、剧情线 | 2 天 |
| **C3** | SEO、真实用户迎接机制（新人首帖 15 分钟内获真人感回复）、创作者激励预留 | 1–2 天 |

12. 邀请制暖场：先内测（你 + 邀请码用户），真用户进来后机器人逐步"退后"为内容供给角色
