## 功能

- 搜索完整邮箱、完整用户 ID、昵称或用户名；状态筛选、分页与真实总数。
- 展示邮箱及验证状态、昵称、登录方式（含钱包/Passkey）、注册时间、最近活跃、USDT 可用与锁定余额。
- 用户详情展示最近 20 笔账本流水与调账记录，保留操作人、原因、调整前后金额及流水 ID。
- 单个有权限的管理员可手工充值、扣减或设置目标可用余额；锁定余额不调整。
- 所有调整必须填写原因，先核对用户和前后金额，再确认入账。
- 手工充值代表站内账本调整，不代表链上充值。

## 资金与权限

- 管理网关读权限：`users.read`。
- 调账需同时具有 `users.read`、`ledger.adjustments.manage`、`ledger.adjustments.post`。
- 核心接口由 `AdminSessionGuard` 验证真实管理员会话或服务通道。仅守卫产生的服务通道身份委托管理网关 RBAC；没有修改全局 RBAC，也没有给审计影子管理员增加权限。
- `LEDGER_ALLOW_SELF_APPROVAL=true` 才能创建新的单人调账。已完成的同编号重试可以查询原结果。
- 金额用 6 位原子单位和 BigInt 计算；设置余额生成差额复式流水，不直接改写余额投影。
- 请求、单人批准、入账与审计在同一事务提交；禁止扣成负数，禁止调整不可用用户或账户。
- 数据库余额锁与确认快照避免并发覆盖；缺失历史投影不会用零代替。
- 操作编号持久化到当前管理员/用户的浏览器 sessionStorage，超时与刷新保留原编号和载荷；服务器事务锁与唯一索引防止重复入账。
- 用户资金写入代理要求同源 Origin；用户响应使用 private/no-store，身份密钥不传给管理前端或管理 API。
