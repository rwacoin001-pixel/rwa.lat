# AI 客服平台知识接入

客服继续使用服务器上的 NVIDIA 配置。Key 不进入代码、前端或知识源。

## 知识来源

- 页面导航：从 `lib/routes-v2.ts` 生成 66 条页面记录，另列客服中心、条款和隐私页面。
- 操作说明：登录/恢复、设备与安全验证、充值倒计时、提现、转账与扫码、投资下单、篮子申赎、预测结算及讨论、资产记录、学习和平台披露。
- 实时公开数据：发布/暂停状态的产品、最新报价及有效期、公开披露文件目录、pilot/active 篮子与策略信息、相关资产参考行情、预测问题与规则、已发布文章、平台已发布主体和准入范围。
- 人工知识：保留后台知识发布、版本、有效期和可见性规则。优先当前语言，并检索英语/中文已发布条目；模型以用户语言回答。

新增产品发布后，下次提问直接查询数据库，无须人工重新导入或等待定时任务。未发布草稿和后台私密资料不会成为客服知识。查询为参数化只读；账户信息仍使用已授权的当前用户工具，不扩大其他用户或资金操作权限。

查询有容量界限：产品按问题匹配排序取 64 条、篮子 32 条、参考资产/预测各 5 条、文章 2 条。这是相关内容检索，不是全库导出；不能用未匹配结果声称某项资料不存在。发布/下架和来源变化会在生成完毕时复核。静态操作文档随版本发布；新增路由需运行生成器。

## 页面链接

模型只可复制服务器提供的页面路径和记录链接。服务器移除未提供的 Markdown 链接；前端仅渲染已注册的站内路径，拒绝外站、脚本、后台、占位符及金额/收款人预填参数。来源引用可直接打开对应页面；原人工知识仍打开原版本。

产品存在、行情存在、可接受申请和已执行成交分别表达。实际费用来自现有预测费率函数；过期报价不能当作当前成交价。披露目录可查询，但未对附件 PDF 全文做 OCR/解析；客服不能编造附件条款。

```powershell
python apps/api/scripts/sync-ai-page-knowledge.py
python apps/api/scripts/sync-ai-page-knowledge.py --check
node apps/api/node_modules/jest/bin/jest.js --runInBand --config apps/api/jest.config.js apps/api/test/ai/ai-platform-knowledge.spec.ts
node apps/api/node_modules/ts-node/dist/bin.js --compiler-options '{"module":"commonjs","moduleResolution":"node"}' scripts/test-ai-navigation-link.ts
```

上线验收：对充值/扫码、产品与篮子、预测派彩、设置语言发送真实匿名客服请求，检查回复语言、有效来源引用、真实页面链接和资金状态表述。模拟新增/下架只在单元测试中进行，不能在生产发布虚假金融产品。
